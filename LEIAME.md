# Marquise Signature – Landing Page

Página estática em HTML, sem build e sem dependências (apenas a fonte Hanken Grotesk via Google Fonts).

## Estrutura
```
index.html        página completa (HTML + CSS + JS no mesmo arquivo, pt-BR)
assets/img/       logo e imagens extraídas do folder Marquise Signature
```

## Publicação (GitHub Pages)
Settings › Pages › Source: branch `main`, pasta `/ (root)`.

## Antes de publicar em produção
- Conectar o formulário de contato a um endpoint/CRM (hoje ele só exibe a mensagem de confirmação; ver `TODO` no fim do index.html).
- Confirmar canais de relacionamento (arquiteta, e-mail, WhatsApp) — os dados atuais vêm do folder e são provisórios.
- Incluir links reais de Política de Privacidade e das condições completas do programa.
- Validar escopo dos kits, nome da plataforma (Loop 8) e prazos com a equipe Marquise.
- Substituir as imagens pelas versões em alta do acervo aprovado e adicionar favicon e og:image.
